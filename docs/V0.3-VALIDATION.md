## 기본 20×20 시나리오 실행

Seed 42, 시작 (0,0), 목표 (19,19), 벽 (8,4)…(8,15). Episodes 1,000; learning rate 0.1; gamma 0.95; epsilon 1.0; decay 0.995; max steps 200.

| 측정 | 결과 |
|---|---:|
| 저장된 Episodes | 1,000 |
| 전체 학습 성공률 | 52.2% |
| 마지막 100회 학습 성공률 | 96.0% |
| 평균 학습 reward | 30.664 |
| 충돌 Episodes | 478 |
| 학습 후 epsilon=0 정책 결과 | Goal |
| greedy 정책 목표 도달 | 38 steps |

초기 무작위 탐험을 포함하는 **학습 지표**입니다. greedy 결과는 동일한 고정 합성 지도에서의 별도 실행이며 hold-out 지도·실기체·일반화 평가가 아닙니다. 전체 1,000개 로그와 Q-table이 실제 생성되었습니다. UI 테스트에서도 별도로 1,000회 학습을 실행했습니다.

## 화면 검증

Qt offscreen 캡처의 Dashboard, Scenario Lab, Replay, Brain Map을 직접 확인했습니다. 첫 캡처에서 글꼴이 네모로 나와 `ui/fonts.py`에서 필요한 경우 Windows 시스템 글꼴을 등록하도록 수정하고 재확인했습니다. Windows 글꼴 파일을 프로젝트에 복제하거나 배포하지 않습니다. Brain Map은 실제 기록된 step의 scores·정책·결과를 4단계 카드와 상세 텍스트로 표시합니다.

샘플 캡처와 summary JSON은 `validation/`에 제공합니다. 검증용 대량 Episode 데이터는 중간 작업 폴더에 생성했으며 기본 사용자 workspace는 비워 두었습니다.
