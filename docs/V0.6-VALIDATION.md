## Curriculum effect

Compact은200/300/400/500회에 승급하여 stage4에서100회 학습했고 Hard 성공0%가 남았습니다. DQN2는200/300/500/600회에 승급, 마지막에stage4에 진입하여 Hard-stage 학습0회입니다. 직접Hard600과의 Hard 비교는 성공35→40%(Curriculum OFF/ON Safety) 대5→5%(Direct)이나 노출환경·평가제도 차이를 포함하므로 인과적 효과를 분리했다고 주장하지 않습니다. Static 승급 평가geometry는 훈련과 같은 고정지도이며 새 reset seed만 사용합니다.

## Gazebo validation

Native process/transport/stepping/controller/sensor provider와 closed-loop interface는 구현했습니다. 실제 Gazebo/Ubuntu 없음, WSL list는 빈 결과였습니다. smoke 실행은 **NOT VERIFIED**, checks={},render_verified=false입니다. 51개 테스트 중 실제 Gazebo integration은 skip1개로 명시합니다.

Unit transport fixture로 world/entity 확인, pose apply/readback, fixed sim-time stepping, fresh LaserScan, goal/collision/reset, serialization/close 계약을 확인했습니다. 실제 물리/렌더링 결과로 해석하지 않습니다. Generated closed-loop SDF는 Sensors plugin과4-ray sensor가 있고 XML parsing이 통과했습니다. native libsdformat/runtime validation은 미검증입니다. Ubuntu 실행 방법은 GAZEBO_INTEGRATION.md와 scripts에 있습니다.
